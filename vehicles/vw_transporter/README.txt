VW TRANSPORTER FOR STARFALLEX

1. Upload vehicles/vw_transporter to a host Starfall's URL whitelist allows.
2. Set BASE_URL at the top of starfall/vwTransporter.txt to that folder.
3. Spawn the chip. Wire the Base input to a prop to attach it, otherwise it follows the chip.
