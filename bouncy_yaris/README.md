# Bouncy Yaris (StarfallEx)

Driveable Toyota Yaris that squashes and stretches in sync with Niko B – "Why's this dealer", using a bounce curve tracked frame-by-frame from the source video.

## Files
| File | What it is |
|---|---|
| `bouncy_yaris.txt` | The Starfall chip script (shared) |
| `yaris.obj` | Car mesh, GMod units, front = +Y, origin at the bottom centre |
| `yaris.png` | Car texture |
| `song.mp3` | Audio track from the video |

## Setup
1. Push this folder to `Equatox/TestAnims` as `bouncy_yaris/` (branch `main`).
2. `BASE_URL` in `bouncy_yaris.txt` already points at:
   `https://raw.githubusercontent.com/Equatox/TestAnims/main/bouncy_yaris/`
3. Put the script in your Starfall folder and spawn it on a processor. The car spawns above the chip.

## Controls
Press E on the car to get in. W/S drive, A/D steer, SHIFT boost, SPACE handbrake/drift.
The song plays from the start when someone gets in and stops when they get out.
